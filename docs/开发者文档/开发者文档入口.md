## 开发自动化功能

仓库级开发约定见根目录 `AGENTS.md`。具体操作按任务查阅：

| 任务 | 文档 |
| --- | --- |
| 添加任务、接入选项、选择参数传递方式 | [如何添加新功能](../knowledge/add-feature.md) |
| 修改识别、动作、共享参数与跨文件引用 | [如何修改现有功能](../knowledge/modify-feature.md) |
| 查阅 Pipeline 字段、候选节点与错误分支 | [Pipeline 参考手册](../knowledge/pipeline-reference.md) |
| 选择检查命令、调试节点、验收完整任务 | [如何测试功能](../knowledge/test-feature.md) |

Pipeline 可以独立完成任务，Python 自定义扩展和 Attach 读取函数按需使用，不要求每个功能都新增固定层数的文件。

## 开发插件

- 请点击链接参考 [插件模板仓库](https://github.com/AsterleedsGuild0/MaaSR-PluginTemplate) 的文档进行开发

## 使用前提醒

- 本仓库同时包含 Python、Node.js 和 Docusaurus 相关工具链。
- 文档改动提交前至少运行一次 `npm run docs:check`。
- 如果你只想使用程序而不参与开发，请转到 [新手指南](/docs/新手指南/新手指南入口)。
