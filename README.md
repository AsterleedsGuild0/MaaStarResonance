## 支持平台

### 1. MuMu模拟器 (星痕共鸣) + Windows桌面端 (星痕共鸣 MAA 小助手)

- 支持 x86_64 / arrch64 的操作系统
- 不支持直连 WeGame 的星痕共鸣
- 不支持其他模拟器，因为只有MuMu有扩充非谷歌原生标准的Adb触控逻辑实现
- 多个用户环境测试通过稳定运行

### 2. 手机端 (星痕共鸣) + 手机端 (星痕共鸣 MAA 小助手)

- 仅支持 **安卓10 +** 的操作系统，星痕共鸣APP本身也是
- 由于系统限制，从 安卓11 开始才可以使用 本MAA小助手 在游戏聊天框输入中文
- 必须已有环境：[Shizuku](https://github.com/RikkaApps/Shizuku) 或者 Root
- 目前已在 [AZMIAO](https://github.com/azmiao) 自用的 红米K80Pro (安卓17 Root) 环境测试通过

### 3. 云手机 (星痕共鸣) + 云手机 (星痕共鸣 MAA 小助手)

- 仅支持 **安卓10 +** 的操作系统，星痕共鸣APP本身也是
- 由于系统限制，从 安卓11 开始才可以使用 本MAA小助手 在游戏聊天框输入中文
- 云手机基本都带 Root 功能，不用担心环境问题
- 目前已在 [AZMIAO](https://github.com/azmiao) 自用的 **云 KVip10 (8H8G 安卓10 Root) 环境测试通过
